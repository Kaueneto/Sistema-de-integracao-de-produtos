# 1. Código-fonte

Repositório configurado como `origin`: https://github.com/Kaueneto/Sistema-de-integracao-de-produtos

O repositório deve conter `src/`, `public/`, `sql/`, `scripts/`, `test/`, `package.json`, `package-lock.json`, `.env.example` e `README.md`. O código inclui tanto o lado consumidor (Grupo 1 → Grupo 3) quanto o lado produtor (Grupo 3 → Grupo 5).

**Conferência antes da entrega:** abrir o link do GitHub em uma janela anônima e verificar se a versão mais recente contém `src/services/customer-integration.service.js` e `sql/01-schema.sql`. Arquivos locais ainda não publicados não aparecem para o professor.

Para executar: instalar Node.js e PostgreSQL, seguir `06-configuracao/guia-configuracao.md`, rodar `npm install` e `npm run dev`.
